# HUD 아이콘 · 배치 시안 (A → C 전달)

HUD 는 C 의 일이다 — WU-31 "HUD: 진행 막대, 탄약 수, 칼 아이콘, 사격 버튼, 일시정지 버튼",
TECH_SPEC "`godot/assets/ui/` (C) 아이콘·폰트·UI 테마".
A 는 **그림만** 만들어 여기(`art/ui/`)에 둔다. C 의 폴더에는 넣지 않았다.
쓸 아이콘은 C 가 `godot/assets/ui/` 로 복사해서 쓴다. 위치·크기·쓸지 말지도 C 가 정한다.

## 아이콘 — `art/ui/icons/`

모두 256×256 PNG, 투명 배경, 어두운 테두리와 옅은 밝은 테, 그림자가 들어 있다.
권총·칼·보급 상자는 게임에 들어가는 3D 모델을 그대로 찍어서, 화면 속 물건과 모양이 같다.

| 파일 | 무엇 | 찍은 모델 | 쓸 곳 (PRD) |
|---|---|---|---|
| `icon_pistol.png` | 권총 옆모습, 총구가 오른쪽 | `weapon_pistol.glb` | 탄약 수 옆, 사격 버튼 |
| `icon_ammo.png` | 탄약 한 발 | 아이콘용으로 따로 만듦 (게임에 탄약 모델은 없다) | 탄약 수 "8 / 12" 앞 (F-15 최대 12발) |
| `icon_knife.png` | 칼, 칼날이 오른쪽 위 | `weapon_knife.glb` | 칼 보유 표시 (F-35) |
| `icon_knife_used.png` | 칼, 흐린 회색 | 위 그림을 흐리게 | F-35 "칼을 쓰면 아이콘이 사라진다" — 바로 지우지 않고 잠깐 이 그림으로 바꿨다 사라지게 할 때 (쓸지 C 가 결정) |
| `icon_supply.png` | 보급 상자 (낙하산 빼고), 빨간 표식이 보이게 | `prop_supply_crate.glb` | 보급 획득 알림 "+6발" (F-23) — **F-72 HUD 목록에는 없는 제안** |

Godot 에서 쓸 때:
- 가져오기(Import) 설정은 기본값(Lossless)으로 둔다. 작게 보여도 256 한 장이면 된다 — `TextureRect` 의 `expand_mode` 로 줄인다
- 휴대폰 화면에서 약 64 - 104 px 크기를 생각하고 만들었다 (시안 그림 기준)

## 배치 시안 — 1920×1080 (TECH_SPEC 6.1 기준 해상도)

노란 네모와 딱지, 흰 점선(안전 영역 F-69)은 설명용이라 실제 화면에는 없다.
배경의 좀비는 A 의 좀비 모델을 찍은 것이고, 길·안개는 대충 그린 것이다.

| 파일 | 배치 | 좋은 점 | 아쉬운 점 |
|---|---|---|---|
| `hud_mock_1_top_center.png` | 진행 막대(상단 중앙) **바로 아래**에 권총·탄약·칼 묶음 | 한눈에 보인다 (처음 요청한 "상단 중앙") | 좀비가 다가오는 화면 가운데를 조금 가린다 |
| `hud_mock_2_top_left.png` | **왼쪽 위**에 권총·탄약·칼 묶음, 가운데는 진행 막대만 | 앞이 트인다 | 탄약 수를 보려면 눈을 옆으로 돌려야 한다 |

두 시안 모두 같은 것:
- 진행 막대는 상단 중앙 그대로 (F-54, WU-15 "화면 상단 진행 막대가 현재 거리 / 1,000m를 표시한다")
- 일시정지는 오른쪽 위, 사격 버튼은 오른쪽 아래 (F-11 "화면 오른쪽의 사격 버튼")
- 아이콘 뒤에 반투명 어두운 판을 깔았다 — 안개(밝은 회색) 위에서 흰 숫자가 묻히지 않게
- 탄약 0발일 때 사격 버튼 비활성 모습(F-13)은 그리지 않았다

## 다시 만들기

```bash
blender -b --factory-startup --python art/blender/render_icons.py   # 모델 촬영 → art/previews/icons_raw/ (커밋 안 함)
python art/ui/finish_icons.py                                       # 테두리 → art/ui/icons/
python art/ui/make_hud_mock.py                                      # 시안 → art/ui/hud_mock_*.png
```

모델을 고치면 위 세 줄을 다시 돌리면 아이콘도 따라 바뀐다.
시안 글씨는 윈도우 기본 글꼴(맑은 고딕)로 그렸고, 이 글꼴은 게임에 넣지 않는다.
