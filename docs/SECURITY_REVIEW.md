## 검증 방법과 공통 근거

- Cloud 재조회: 본편 마이그레이션 4건, `public` 테이블 10개 모두 RLS 켬, 관리자 보기 3개, DB 함수 8개, Edge 함수 8개 `ACTIVE`·JWT 검증 켬. 최신 `support-chat`은 **v6**이며 v3→v6의 배포 소스 변경 여부는 확인하지 못했다. 사용자 승인 아래 검증용 질문 2건의 Cloud 응답/DB 상태를 확인하고 테스트 후 Auth 사용자·`public` 10개 테이블 행 0을 별도 재조회했다.
- 계정·진행, 결제 DB, 문의·관리자·탈퇴는 각각 격리된 익명 사용자로 별도 검증하고 정리했다. 결제의 1회 지급은 합성 `paymentKey`로 DB RPC만 확인했다. 이어서 **가짜 결제 키로 Toss 승인 함수 1회 호출→서버 HTTP 502·주문 ready/구매·지급 0**을 확인했지만 제공자 측 실제 수신·거절 로그와 성공 승인은 미검증이다. Android SDK도 호출하지 않았다. 안내 검증은 `support-chat` 질문 2건의 Cloud 응답·DB 상태를 확인했지만 **OpenAI 제공자 측 요청/과금 로그는 확인 전**이다.
- 로컬 Deno 전체 회귀 `73 passed / 0 failed`; Toss 부정 경로 스크립트 추가 후 lint 57 files, Edge 8개·기존 검증 스크립트 6개 및 새 Toss 스크립트 type check 통과. `db lint --schema public --fail-on error`는 종료 코드 0이나 `admin_reply.target_id` 미사용 변수 경고 1건이 있다.
- 상세 실행·원격 재조회 근거: `../📋YH_3D_Game_MVP_현재 진행 현황.md`의 2026-09-29~30 항목과 `../backend/검증/`의 승인 보호 스크립트. 이 문서의 결과는 **그때 실행한 경로**에 한정된다.

## 배포 전 열려 있는 위험과 의존성

1. **필수 기능 미완료**: `TOSS_TEST_SECRET_KEY`, `OPENAI_API_KEY`, `OPENAI_MODEL`은 후속 조회에서 세 **이름의 등록**만 확인했다. 값·모델 접근 권한·토스 클라이언트 키와의 세트 매칭은 검증 전이다. 앞서 `TOSS_SECRET_KEY`로 잘못 안내했으나 코드는 그 이름을 읽지 않는다. 제공자 키 값은 이 문서·채팅·Git에 남기지 않는다.
2. **게임 안내 기준 미확정**: 최신 Cloud `support-chat` v6은 검증용 문구 질문에 정확한 응답을 했지만, 배포 소스 변경과 제공자 사용량 로그를 독립 확인하지 않았다. 검증 문구는 **실제 게임 사실이 아니다**. 실사용 전 B의 게임 구현과 맞는 안내로 교체해야 한다.
3. **관리 도구 경계**: 앱 관리자 API의 역할 검사와 Studio 프로젝트 멤버의 DB 접근 권한은 다르다. 일반 플레이어에게 Studio 접근을 부여하지 않는다. 관리자 실제 사용 흐름·권한 주체는 팀 확인이 필요하다.
4. **출시 판단 보류**: 개인정보 입력 경고 UI, 서명 APK/웹 빌드의 비밀 키 검사, Toss 실제 승인 성공·본편 게임 안내/제공자 로그·이메일 복구·B 보안 교차 검토가 끝나지 않았다. **확정된 고위험 취약점 0건이라는 주장이나 체크리스트의 ‘위험도 높음 0건’ 통과 표시는 하지 않는다.**
