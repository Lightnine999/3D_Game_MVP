# 3D_Game_MVP — 안개 속 좀비 생존 러너 (가칭)

> 좀비가 가득한 안개 낀 밤 들판을 1인칭으로 달려, 탈출 지점까지 살아남아라.

AI 도구(Claude, 나노바나나)와 무료 에셋만으로 **Google Play에 출시할 수 있는 3D 모바일 게임**을 3인 팀이 만들 수 있는지 검증하는 프로젝트입니다. 먼저 스테이지 1개짜리 MVP를 3일 안에 만들고, 테스터들의 반응으로 재미를 확인합니다.

| 항목 | 내용 |
|---|---|
| 장르 | 1인칭 좀비 생존 러너 (레퍼런스: Into the Dead) |
| 플랫폼 | Android (Google Play) · 웹 체험판 |
| 엔진 | Godot 4 |
| 현재 상태 | 🛠️ **개발 준비 중** — 문서 v0.2 완료, WU-00 폴더 초기화 완료 |
| GitHub | (원격 저장소 생성 후 링크 추가) |

> **저장소 구성**: 이 프로젝트는 **독립 저장소**입니다 (TECH_SPEC Q6 결정, 2026-09-28). 로컬 위치는 `~/3D_Game_MVP`이고, 다른 실습 워크스페이스와 섞지 않습니다. 커밋·푸시 전에는 `git remote -v`로 원격을 확인하세요.

## 🎮 게임 소개

### 이렇게 플레이해요
1. **스테이지 카드**에서 이번 판의 미션 3개를 확인하고 출발해요.
2. 캐릭터는 **자동으로 앞으로 달려요.** 좌우로 움직여 좀비와 장애물을 피해요.
3. 권총은 들고 있지만 **총알은 0발.** 하늘에서 낙하산으로 떨어지는 보급 상자를 주워야 쏠 수 있어요.
4. 좀비에게 잡히면 **칼로 딱 한 번** 뿌리칠 수 있어요. 두 번째로 잡히면 끝이에요.
5. 1,000m를 달려 **탈출 트럭**에 도착하면 클리어!

### 핵심 재미
| 요소 | 내용 |
|---|---|
| 🌫️ 안개 속 긴장감 | 시야 30-40m의 밤 들판에서 좀비가 갑자기 모습을 드러내요 |
| 🔫 쏠까, 피할까 | 총알이 귀해서 매 순간 판단이 필요해요 |
| 🧟 좀비 4종 | 느린 **워커**, 옆에서 달려드는 **러너**, 총알 4발을 버티는 **탱커**, 풀숲에 숨은 **매복** |
| 🚧 장애물 | 폐차·드럼통·쓰레기 더미에 부딪히면 비틀거리며 느려지고, 그 사이 좀비가 다가와요 |
| ⭐ 스테이지 미션 | 생존 / 좀비 15마리 처치 / 헛간을 통과해 달리기 — 남은 미션이 "한 판 더"를 부르죠 |
| 🏞️ 와이드 화면 | 폰 화면이 넓을수록 좌우가 더 보여서, 광활한 들판을 달리는 느낌을 줘요 |

### 조작
| 동작 | 방법 |
|---|---|
| 좌우 이동 | 화면 왼쪽 드래그 **또는** 폰 기울이기 (설정에서 선택) |
| 사격 | 화면 오른쪽 사격 버튼 (가장 가까운 좀비 자동 조준) |
| 일시정지 | 화면 위 일시정지 버튼 |

## 🛠️ 기술 스택

| 영역 | 도구 |
|---|---|
| 게임 엔진 | Godot 4 (GDScript, Mobile 렌더러) |
| 콘셉트 아트 | 나노바나나 (Gemini 이미지 생성) |
| 배경·소품·장애물 | Blender 5.2 — **화면 없이 Python 스크립트로 생성** |
| 좀비 캐릭터·모션 | Mixamo |
| 무기·사운드 | CC0 무료 에셋 |
| 백엔드 | Supabase (게스트 로그인, 랭킹, 구매 기록) |
| 결제 (앱) | Google Play Billing |
| 결제 (웹, 테스트) | 토스페이먼츠 테스트 결제 |
| 웹 배포 | Vercel |

**바이브 코딩 방식**: 모델·씬·코드가 모두 텍스트 파일이라, Claude가 만들고 명령줄로 실행하고 렌더 이미지·스크린샷으로 결과를 확인합니다. 사람은 Blender나 Godot 에디터를 열지 않아도 됩니다.

```
나노바나나 콘셉트 → Blender 스크립트 / Mixamo → 자동 검사 → .glb
  → Godot 게임 → 자동 테스트 → Android .aab → Google Play
```

자세한 구조와 결정 이유는 [TECH_SPEC.md](DevelopDoc/TECH_SPEC.md)에 있습니다.

## 🚀 실행 방법

> 아직 개발 전이라 실행할 수 있는 코드가 없습니다. 아래 명령은 개발 후 제공될 **예정**입니다 (TECH_SPEC 5.1, 9.1).

```bash
./pipeline.sh assets          # 모든 3D 에셋 생성 → 검사 → Godot 가져오기
./pipeline.sh install-device  # USB로 연결한 안드로이드 폰에 설치
./pipeline.sh build-android   # 서명된 .aab 빌드 (Google Play 업로드용)
./pipeline.sh build-web       # 웹 체험판 빌드
```

필요한 도구 (2026-09-28 설치 확인)

| 도구 | 버전 |
|---|---|
| Godot + 내보내기 템플릿 | 4.7.2 stable |
| Blender | 5.2.2 LTS |
| OpenJDK | 17 |
| Android SDK | build-tools 35.0.1, platforms android-35, NDK 28.1.13356709, CMake 3.10.2.4988404 |
| Supabase CLI / Vercel CLI | 2.118.0 / 59.16.0 |

환경변수 `JAVA_HOME`(OpenJDK 17)과 `ANDROID_HOME`(Android SDK 경로)이 설정되어 있어야 합니다.

## ⚠️ 주의 사항

**이 저장소는 공개(Public)입니다.** 저장소를 처음 받으면 아래 두 가지를 먼저 해 주세요.

```bash
git config core.hooksPath scripts/git-hooks
```

```bash
git config user.email "<GitHub ID>+<GitHub 아이디>@users.noreply.github.com"
```

- 첫 번째 명령은 **비밀 키 검사 훅**을 켭니다. 커밋할 때마다 비밀 키 패턴(Gemini·토스·Supabase·GitHub 키, 개인키), 커밋 금지 파일(`.env`, 키스토어, 서비스 계정 JSON), 10MB 넘는 파일을 검사해서 발견되면 커밋을 막습니다.
- 두 번째 명령은 커밋 기록에 개인 이메일이 공개되지 않게 합니다.
- 테스터 명단, 설문 원본, 계약·정산 같은 **내부 문서는 `private/` 폴더**에 두세요. 이 폴더는 통째로 커밋되지 않습니다.

- **비밀 값은 커밋하지 않습니다.** API 키, 결제 시크릿 키, 서비스 계정 JSON, 앱 서명 키스토어, `.env`는 git에서 제외합니다 (TECH_SPEC 11.2, 12장).
- **Mixamo 원본 파일은 저장소에 올리지 않습니다.** 게임 안에서 쓰는 건 허용되지만 원본 재배포는 금지되어 있습니다.
- 외부 에셋은 전부 `ASSETS_LICENSE.md`에 출처와 라이선스를 기록합니다.
