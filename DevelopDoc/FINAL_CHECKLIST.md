## 0. 사용 규칙

1. 프로젝트는 **게이트(관문) 6개**를 순서대로 통과한다. 앞 게이트를 통과해야 다음 게이트를 점검한다.
2. 각 게이트는 **모든 항목이 체크**되어야 통과다. 하나라도 비면 통과하지 못한 것이다.
3. 체크할 때는 **근거**(측정값, 스크린샷 경로, 로그, Play Console 화면, 설문 집계)를 `근거` 칸이나 `docs/evidence/final/`에 남긴다.
4. 게이트 통과 시 **3인 전원이 서명**(이름 + 날짜)한다 (9장).
5. 공통 품질 항목(7장)은 **모든 게이트에서** 다시 확인한다.
6. 👤 = 사람이 직접 확인해야 하는 항목.

### 게이트 한눈에 보기
| 게이트 | 이름 | 통과 의미 | 관련 WU |
|---|---|---|---|
| G1 | MVP 완성 | 폰에서 스테이지 1개를 처음부터 끝까지 제대로 즐길 수 있다 | WU-00 - WU-35 |
| G2 | 비공개 테스트 완료 | 재미가 검증되었고, 정식 출시 조건(12명 × 14일)을 채웠다 | WU-40 - WU-42 |
| G3 | 백엔드 | 로그인·랭킹이 안전하게 동작한다 | WU-50 - WU-52 |
| G4 | 웹 테스트 결제 (토스) | 웹에서 테스트 결제 → 지급이 안전하게 동작한다 | WU-55 - WU-57 |
| G5 | 앱 결제 (구글) | 앱에서 테스트 결제 → 지급이 안전하게 동작한다 | WU-60 - WU-63 |
| G6 | 정식 출시 | Google Play에 공개되었다 | WU-70 - WU-71 |

## 1. G1 — MVP 완성

### 1.1 작업 완료
- [ ] WU-00 - WU-35의 모든 작업이 ✅ 완료 상태다 (범위 제외 ✂️ 항목은 사용자 승인 기록이 있다)

### 1.2 핵심 플레이 (👤 테스트 폰에서 직접 확인)
- [ ] 타이틀 → 스테이지 카드 → 게임 → 결과 → 다시하기 흐름이 막힘 없이 이어진다
- [ ] 스테이지 카드에 이름·설명·목표 거리·미션 3개가 보인다 (F-90)
- [ ] 자동 달리기 + 드래그 이동이 자연스럽다 (F-01, F-02)
- [ ] 기울이기 모드로 바꿔도 한 판을 끝까지 할 수 있다 (F-03 - F-05)
- [ ] 시작 탄약 0발 → 낙하산 보급을 주워야 쏠 수 있다 (F-10, F-20 - F-24)
- [ ] 자동 조준 사격이 의도한 좀비를 맞힌다 (F-11)
- [ ] 좀비 4종(워커·러너·탱커·매복)이 모두 등장하고 서로 다르게 행동한다 (F-40 - F-43)
- [ ] 처음 잡히면 칼로 탈출, 두 번째로 잡히면 사망한다 (F-30 - F-34)
- [ ] 장애물에 부딪히면 비틀거리며 느려지고, 그 사이 좀비가 가까워지는 순간이 생긴다 (F-57 - F-59)
- [ ] 1,000m 지점 탈출 트럭에 도착하면 클리어된다 (F-55)
- [ ] 미션 3개(생존·15마리 처치·헛간 통과)가 판정되고 결과에 ★로 표시된다 (F-91 - F-94)

### 1.3 분위기·화면 (👤)
- [ ] 안개 속에서 좀비가 나타날 때 긴장감이 있다 — 팀 3인 모두 "무섭다/긴장된다"에 동의 (H1 사전 점검)
- [ ] 매복 좀비의 점프 스케어가 동작한다 (F-63)
- [ ] 16:9, 20:9, 21:9 비율에서 화면이 꽉 차고, 넓은 폰일수록 좌우가 더 보인다 (F-66)
- [ ] 근경·중경·원경이 구분되어 들판이 넓고 깊게 느껴진다 (F-67, F-68)
