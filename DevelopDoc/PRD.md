## 1. 배경과 목적

### 1.1 배경
- 3인 비개발자가 AI 도구(Claude, 나노바나나)와 무료 에셋으로 Google Play에 출시 가능한 3D 게임을 만들 수 있는지 검증한다.(결제 시스템을 토스페이먼츠로도 테스트해본다.)
- 레퍼런스 Into the Dead는 "어둠 속에서 좀비가 나타나는 긴장감"이 핵심 재미다. 이 재미는 사실적인 그래픽이 아니라 **안개·조명·사운드·등장 타이밍**에서 나오므로, 로우폴리 에셋으로도 재현할 수 있다고 판단했다.

### 1.2 MVP 목적
**스테이지 1개**를 완성도 있게 만들어 테스터에게 플레이시키고, 아래 가설을 검증한다.

| # | 가설 | 검증 방법 |
|---|---|---|
| H1 | 안개 속에서 좀비가 나타나는 긴장감이 로우폴리 그래픽으로도 전달된다 | 설문 "무서웠다/긴장됐다" 5점 척도 평균 3.5 이상 |
| H2 | 탄약을 낙하산 보급으로만 얻는 구조가 "쏠까, 피할까" 고민을 만든다 | 설문 + 플레이 로그 (보급 획득률, 탄약 소진 시점) |
| H3 | 칼 1회 사용 규칙이 "한 번의 실수는 봐준다"는 적정 긴장감을 준다 | 칼 사용 후 클리어 비율, 설문 "억울하게 죽었다" 비율 |
| H4 | 주변에 폐차들과 폐드럼통,쓰레기 등등이 배치되어 장애물에 부딛치거나 피한다|장애물을 피할때 좀비들의 동선과 만날수있는 변수를 만든다. |
| H5 | 좀비 4종이 구간마다 다른 긴장감을 만들어 3-4분 플레이가 지루하지 않다 | 설문 "다시 하고 싶다" 5점 척도 평균 3.5 이상, 평균 재시도 2회 이상 |
| H6 | 스테이지 미션 3개가 "한 판 더" 동기를 만든다 (클리어 후에도 남은 미션을 위해 재도전) | 클리어 후 재도전 비율, 설문 "미션 때문에 다시 했다" |
| H7 | 와이드 화면과 깊이감 연출이 "광활한 들판을 달린다"는 느낌을 준다 | 설문 "들판이 넓게 느껴졌다" 5점 척도 평균 3.5 이상 |

## 3. 게임 개요

### 3.1 한 줄 소개
좀비가 가득한 안개 낀 밤 들판을 1인칭으로 달려 탈출 지점까지 살아남아라.

### 3.2 핵심 게임 루프
```
스테이지 카드에서 미션 3개 확인
  → 달린다 (자동 전진)
  → 안개 속에서 좀비·장애물 발견
  → 판단: 피할까(좌우 이동) / 쏠까(탄약 소모)
     (장애물을 피하다 좀비 동선과 겹치는 순간이 생긴다)
  → 낙하산 보급을 주워 탄약 확보
  → 잡히면 칼로 한 번은 탈출 / 두 번째는 사망
  → 목표 거리 도달 → 탈출 성공
  → 결과에서 미션 달성 확인 → 남은 미션을 위해 다시 도전
```

### 3.3 승리·패배 조건
| 구분 | 조건 |
|---|---|
| 승리 | 목표 거리(초기값 1,000m)를 달려 **탈출 지점**(버려진 트럭)에 도착 |
| 패배 | 칼이 없는 상태에서 좀비에게 잡힘 → 물려서 사망 |
| 미션 | 승리와 별개로 스테이지 미션 3개의 달성 여부를 판정한다 (4.10). 미션을 못 해도 탈출하면 클리어다 |

### 4.8 UI·화면 흐름

## 8. 플레이테스트 계획

### 8.1 방법
- Google Play 비공개 테스트 트랙으로 배포하고, 결제 없이 무료로 플레이한다.
- 테스터에게 **최소 3판 이상** 플레이 후 설문 작성을 요청한다.

### 8.2 설문 문항 (초안)
| # | 문항 | 형식 | 연결 가설 |
|---|---|---|---|
| 1 | 게임이 무섭거나 긴장됐나요? | 1-5점 | H1 |
| 2 | 탄약이 부족해서 쏠지 피할지 고민한 적이 있나요? | 1-5점 | H2 |
| 3 | 억울하게 죽었다고 느낀 적이 있나요? 있다면 언제였나요? | 예/아니오 + 서술 | H3 |
| 4 | 가장 무서웠던 좀비는 무엇인가요? | 4종 중 선택 | H5 |
| 5 | 이 게임을 다시 하고 싶나요? | 1-5점 | H5 |
| 6 | 조작 방식은 무엇을 썼고, 편했나요? | 선택 + 1-5점 | 조작 |
| 7 | 버벅이거나 이상한 점이 있었나요? | 서술 | 품질 |
| 8 | 돈을 낸다면 어떤 것을 사고 싶나요? | 서술 | F-82 상품 구성 |
| 9 | 장애물을 피하다가 좀비와 마주쳐 위험했던 순간이 있었나요? | 예/아니오 + 1-5점(재미) | H4 |
| 10 | 남은 미션 때문에 한 판 더 한 적이 있나요? | 예/아니오 | H6 |
| 11 | 들판이 넓고 깊게 느껴졌나요? | 1-5점 | H7 |

### 8.3 MVP 성공 기준
| 지표 | 목표 |
|---|---|
| 테스터 수 | 12명 이상, 14일 연속 참여 |
| 클리어율 | 전체 판의 30-60% (너무 쉽거나 어렵지 않음) |
| 평균 재시도 | 테스터당 2회 이상 |
| 설문 1번 (긴장감) | 평균 3.5 이상 |
| 설문 5번 (재플레이 의향) | 평균 3.5 이상 |
| 강제 종료 | 세션의 1% 미만 |

기준에 미달하면 원인(난이도, 조작, 분위기, 성능)을 분석해 수정한 뒤, 정식 출시 전에 다시 검증한다.

## 9. 가정과 미결 사항

### 9.1 가정 (다르면 수정)
| # | 가정 |
|---|---|
| A1 | 칼은 잡힌 순간 **자동으로** 사용된다 (버튼 입력 불필요) |
| A2 | 사격은 **자동 조준**이다 (정밀 조준 없음) |
| A3 | 칼은 먼저 휘둘러 공격하는 무기가 아니라 **잡혔을 때 탈출용**으로만 쓴다 |
| A4 | 칼은 스테이지 중간에 추가로 얻을 수 없다 |
| A5 | 탱커에게 잡혀도 다른 좀비와 같은 잡힘 규칙을 적용한다 |
| A6 | 장애물은 총으로 부술 수 없다. 좀비도 장애물을 넘지 못하고 돌아서 온다 |
| A7 | 미션 달성은 보상 없이 별 표시만 한다 (보상은 P2, F-96) |

### 9.2 미결 사항
| # | 항목 | 결정 시점 |
|---|---|---|
| Q1 | 칼 사용을 자동(A1)으로 할지, 제한 시간 안에 버튼을 누르는 방식(QTE)으로 할지 | MVP 1차 플레이 후 |
| Q2 | 정식 게임 이름 | 비공개 테스트 업로드 전 |
| Q3 | 인앱 상품 구성 (칼 추가 구매 등은 밸런스를 해칠 수 있어 신중히 결정) | 설문 8번 결과 이후 |
| Q4 | ~~테스트 폰 성능 목표~~ → **결정**: Galaxy S24 Ultra 60fps + 중급 기기 30fps (TECH_SPEC 10.3) | 2026-09-28 |
