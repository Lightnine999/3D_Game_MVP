## 0. 사용 규칙

### 0.1 완료 판정
1. 작업의 **완료 조건이 전부 체크**되어야 완료로 본다. 하나라도 비면 "진행 중"이다.
2. 체크할 때는 **근거**를 남긴다: 명령 실행 결과, 테스트 통과 로그, 스크린샷 경로(`docs/evidence/WU-xx/`), 사용자 확인 중 하나.
3. "코드를 작성했다"는 완료가 아니다. **실행해서 확인한 결과**가 있어야 한다.
4. 👤 표시는 **사용자가 직접 해야 하는 항목**이다 (계정, 로그인, 키, 다운로드, 폰 설정, 플레이 피드백).

### 0.2 상태 표기
`⬜ 대기` · `🟦 진행 중` · `✅ 완료` · `⏸ 보류` · `✂️ 범위 제외`

### 0.3 작업 기록 형식
각 작업 표의 항목 의미:
- **PRD**: 이 작업이 구현하는 PRD 기능 ID
- **선행**: 먼저 끝나야 하는 작업
- **예상**: 예상 작업 시간 (Claude 작업 + 사용자 확인 포함)
- **담당**: 소유자와 날짜 (TECH_SPEC 13.1 파일 소유권 기준)
- **산출물**: 작업이 끝나면 생기는 파일·결과

### 1.3 일정이 밀릴 때 줄이는 순서
마감을 지키지 못할 조짐이 보이면 **팀이 상의한 뒤** 아래 순서로 범위를 줄인다. 임의로 빼지 않는다.
1. P1 기능 전부 (F-25, F-45, F-56, F-65, F-76, F-77, F-134)
2. 탱커 좀비의 전용 모델 → 워커 모델 확대(1.3배) + 색 변경으로 대체
3. 기울이기 조작(WU-30) → 마감 이후로 미룸
4. 조작 안내 화면(F-71) → 첫 판 화면 위 텍스트 힌트로 대체
5. 웹 빌드·웹 결제(WU-55) → 앱 테스트 결제만 제출
6. 관리자 보기 3개(WU-54) → 문의 보기(`admin_support`) 하나만

**줄이지 않는 것**: 게임 한 판 완주, 게스트·이메일 로그인, 회원 탈퇴, 앱 테스트 결제 1건 성공, 문의 채팅 1회 왕복, 관리자 문의 확인, 테스트 패널, 보안 점검 보고서, 서명된 APK.
