| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.2 |
| 작성일 | 2026-09-28 |
| 상태 | DRAFT (검토 중) |
| 기준 문서 | `PRD.md` v0.2 (무엇을), `TECH_SPEC.md` v0.2 (어떻게) |
| 관련 문서 | `FINAL_CHECKLIST.md` (최종 체크리스트) |

> 이 문서는 PRD의 기능을 **하나씩 끝낼 수 있는 작업 단위(WU)**로 쪼갠다.
> 각 작업에는 **완료 조건 체크리스트**가 있고, 전부 체크되어야 그 작업이 끝난 것이다.

## 0. 사용 규칙

### 0.1 완료 판정
1. 작업의 **완료 조건이 전부 체크**되어야 완료로 본다. 하나라도 비면 "진행 중"이다.
2. 체크할 때는 **근거**를 남긴다: 명령 실행 결과, 테스트 통과 로그, 스크린샷 경로(`docs/evidence/WU-xx/`), 사용자 확인 중 하나.
3. "코드를 작성했다"는 완료가 아니다. **실행해서 확인한 결과**가 있어야 한다.
4. 👤 표시는 **사용자가 직접 해야 하는 항목**이다 (계정, 로그인, 키, 다운로드, 폰 설정, 플레이 피드백).

### 0.2 상태 표기
`⬜ 대기` · `🟦 진행 중` · `✅ 완료` · `⏸ 보류` · `✂️ 범위 제외`

### 0.3 작업 기록 형식
각 작업 표의 항목 의미:
- **PRD**: 이 작업이 구현하는 PRD 기능 ID
- **선행**: 먼저 끝나야 하는 작업
- **예상**: 예상 작업 시간 (Claude 작업 + 사용자 확인 포함)
- **산출물**: 작업이 끝나면 생기는 파일·결과

| A. 에셋 | (미정) | WU-04(B) | WU-10, WU-11, WU-12 | WU-20, 무기·보급·장애물 모델 | WU-32 사운드 소스 조달(C) | WU-70 스토어 이미지 |

### 1.3 일정이 밀릴 때 줄이는 순서
3일 안에 끝나지 않을 조짐이 보이면 **사용자와 상의한 뒤** 아래 순서로 범위를 줄인다. 임의로 빼지 않는다.
1. P1 기능 전부 (F-25, F-45, F-56, F-65, F-76, F-77)
2. 탱커 좀비의 전용 모델 → 워커 모델 확대(1.3배) + 색 변경으로 대체
3. 기울이기 조작(WU-30) → 비공개 테스트 첫 업데이트로 미룸
4. 조작 안내 화면(F-71) → 첫 판 화면 위 텍스트 힌트로 대체
